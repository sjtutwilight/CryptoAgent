# Metadata Core 设计文档

## 模块定位
元数据管理核心服务，提供数据资产的元数据管理能力。

## 核心功能
- 元数据采集：表结构、字段定义、血缘关系
- 元数据存储：统一元数据仓库
- 元数据查询：API接口与搜索能力
- 血缘追踪：数据流向与依赖关系

## 技术栈
- Spring Boot
- PostgreSQL（元数据存储）

## 数据流
```
数据源 → 元数据采集器 → 元数据仓库
                          ↓
                    元数据API → 前端/用户
```

## 关键设计
- 统一元数据模型：表、字段、血缘、标签
- 自动采集：定时扫描数据源
- 版本管理：元数据变更历史
