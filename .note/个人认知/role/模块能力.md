## 功能性能力
**配置模型表达力**：是否能完整表达任务、依赖、重试、超时、并发、路由、参数化。
**模板与复用能力**：是否支持模板继承、变量替换、默认值、环境覆盖。
**校验能力**：语法校验、语义校验、跨字段约束校验、错误定位是否精确到字段路径。
**解析与装配能力**：能否稳定将 YAML 转换为运行时对象，且行为可预测。
**版本与兼容能力**：配置版本管理、向后兼容、弃用字段迁移策略。
动态生效能力：热更新、增量 apply、回滚、dry-run/resolve/validate。
可观测控制能力：是否支持查看生效配置、差异对比、变更审计。
非功能性能力

可靠性：坏配置隔离、部分失败可恢复、失败可回滚。
性能：大配置解析耗时、内存占用、热更新延迟。
安全性：敏感字段管理、密钥脱敏、权限控制、防注入。
一致性：多实例加载一致、配置传播时序一致、幂等生效。
可维护性：结构清晰、字段命名统一、文档与 schema 同步。
可测试性：单测覆盖校验规则、集成测试覆盖真实配置工件。
工程与运维能力

Schema 治理：有明确 JSON Schema/OpenAPI/内部类型定义。
发布治理：配置评审门禁、CI 校验、灰度发布策略。
问题定位：错误码、日志字段标准化、可快速定位到 role/字段。
变更追踪：谁在何时改了什么、影响哪些任务、是否可追溯。
生态工具：lint、format、自动补全、IDE 提示、配置生成器。
