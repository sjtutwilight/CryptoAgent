## ADDED Requirements

### Requirement: 系统必须生成统一的决策链效率指标
系统 MUST 按固定统计窗口产出 Codex 决策链效率指标，至少覆盖重复步骤次数、低效读取比、工具失败热点、首次有效产出时延。

#### Scenario: 每日窗口成功产出指标快照
- **WHEN** 到达每日统计任务执行时间
- **THEN** 系统 MUST 产出当日指标快照并保存至可查询位置

#### Scenario: 指标口径可追溯
- **WHEN** 使用者查看任一效率指标
- **THEN** 系统 MUST 提供对应事件口径说明与时间窗口定义

### Requirement: 系统必须识别高频重复步骤并形成候选清单
系统 MUST 识别同类会话中反复出现的高频操作序列，并输出可脚本化候选列表。

#### Scenario: 识别重复命令链
- **WHEN** 多个会话在窗口内出现相同命令/工具序列且超过阈值
- **THEN** 系统 MUST 生成“脚本化候选”并附带出现频次与总耗时

#### Scenario: 候选带证据
- **WHEN** 输出脚本化候选
- **THEN** 系统 MUST 附带至少一个代表性事件样本与统计摘要

### Requirement: 系统必须识别低价值读取模式
系统 MUST 识别“高读取、低改动、低验证”的低价值行为模式并输出治理提示。

#### Scenario: 触发低效读取判定
- **WHEN** 会话在窗口内读取行为显著高于改动和验证行为且超过阈值
- **THEN** 系统 MUST 记录低效读取事件并标记建议补充文档或索引

#### Scenario: 低效读取趋势可观察
- **WHEN** 连续多日出现低效读取模式
- **THEN** 系统 MUST 在看板中呈现趋势并触发关注信号
