# Agent 设计文档

## 模块定位
AI Agent应用层，基于LangGraph实现的智能数据分析助手（MVP版本）。

## 核心功能
- 自然语言查询：通过对话方式查询数据平台指标
- 工具调用：封装后端API为Agent工具
- 上下文管理：基于sessionId的多轮对话历史

## 技术栈
- LangGraph（ReAct Agent）
- DeepSeek（大模型）
- Python

## 数据流
```
用户查询 → Agent → 工具选择 → 后端API调用 → 结果整理 → 用户
              ↓
        对话历史管理（压缩/摘要）
```

## 关键设计
- MVP定位：展现端到端能力，非生产级可靠性
- 工具分类：市场分析、风险监控、跨市场对比、标的筛选
- 短期记忆：超过阈值自动压缩为摘要

## 未来改进方向
- Text-to-SQL支持
- 多模态输出（图表生成）
- 多Agent协同
- 观测+执行反馈闭环
